# 税金台账

12 个月增值税与企业税负率台账，单文件网页应用，零依赖、免安装。

**在线使用**：https://terrykwok19-commits.github.io/tax-ledger/

## 功能

- **收入三行拆分**：货物开票收入（13%）、未开票收入（13%，税率可单独改）、服务收入（6%）
- **销项税**：自动计算，也可手动覆盖，手改后单元格变黄底并出现 ↺ 恢复按钮
- **进项税**：手工填写
- **增值税** = 销项税 − 进项税，负数标红并提示留抵，附加税基数按 0 计
- **附加税**：城建 7%、教育 3%、地方教育 2%，带**六税两费减半开关（默认开 → 3.5/1.5/1）**，三行均可手动覆盖
- **印花税、企业所得税**：选填，各带开关，关掉后整行隐藏且不进合计
- **自定义税种**：点「＋ 税种」任意新增（房产税、土地使用税、车船税、消费税、残保金…），金额手工填写；双击行标题改名，行尾 ✕ 删除（同时清掉 12 个月数据）。新税种自动计入税金合计、累计列、税负率与导出
- **四个税负率**：本月/本年 × 增值税税负率/综合税负率，分母为 0 时留空不报错
- **折叠累计**：点任一月表头，前面所有月份折叠成一列「1–N月累计」，点累计表头展开
- **三行高亮**：增值税行（橙）、企业所得税行（紫）、税金合计行（蓝）整行填色，深浅两套主题各自适配

## 数据存储

所有数据只存在**当前浏览器的 localStorage**，不上传任何服务器。

- 换浏览器、换电脑、清缓存 → 数据不会跟过去
- 重要数据请用「导出存档」保存 JSON，或「导出 Excel」留档

## 导入导出

- **导出 Excel**：真正的 `.xlsx`（自写 ZIP + OOXML），含 `明细台账` 和 `税负率` 两个工作表，月份为列、税种为行，空白月留空不写 0
- **导入 Excel**：支持 `.xlsx` / `.xls`（网页表格形式）/ `.csv`，按「1月…12月」表头定位列，按首列中文标签匹配税种；销项税与附加税的导入值若与自动计算值相差超过 0.005，自动标记为手动覆盖。表中认不出的税种行（如「房产税」「车船税」）会自动创建为自定义税种并带入数据，不会丢行

## 本地使用

`index.html` 直接用浏览器打开即可，功能与线上完全一致。注意本地文件与线上网页属于不同的存储域，两处数据互不相通。
