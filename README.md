# 税金台账

12 个月增值税与企业税负率台账，单文件网页应用，零依赖、免安装。

**在线使用**：https://terrykwok19-commits.github.io/tax-ledger/

## 核心设计：项目行可增减，计算逻辑不变

表格里的「项目」不是写死的，随时可加可删。合计口径永远是**当前存在的行相加**，删掉一行自动从合计里消失。

| 行类型 | 加按钮 | 参与的计算 |
|---|---|---|
| 收入项 | ＋ 收入 | 计入「收入合计」；按各自税率计入「销项税」 |
| 增值税附加 | ＋ 附加 | 计入「税金合计」；金额 = 增值税 × 费率（可减半） |
| 手工税费 | ＋ 税费 | 计入「税金合计」；金额手工填 |

固定不变的四条规则：**收入合计 = 所有收入项之和**、**销项税 = Σ(收入项 × 各自税率)**、**增值税 = 销项税 − 进项税**、**税金合计 = 增值税 + 所有附加 + 所有手工税费**。

举例：删掉「服务收入」，收入合计就只剩货物开票收入 + 未开票收入，销项税同步少掉服务那部分；再加一行「劳务收入 6%」，收入合计和销项税自动带上它。

### 行操作

- **调整顺序**：按住行标题（名称左侧的点阵手柄）上下拖动，松手即落位，顺序随存档保存、导出 Excel 也按此顺序
- **改名**：双击行标题
- **改税率/费率**：点行标题后面的百分比徽标（如 13%、3.5%）
- **删除**：点行标题最右的 ✕（有数据时会二次确认，一并清掉 12 个月的值）
- 收入合计、销项税、进项税、增值税、税金合计、主营业务成本、毛利、毛利率为固定行，不可删改、不可拖动（但可以作为拖动落点）

## 毛利与毛利率

「主营业务成本」行**按月在格子里手填**，填完自动出两行：

- **毛利 = 收入合计 − 主营业务成本**
- **毛利率 = 毛利 ÷ 收入合计**，按百分比显示

口径细节：

- 成本没填（也没填 0）的月份，毛利与毛利率留空，不会因为只填了收入就显示 100%
- 合计列的毛利率不是各月百分比的平均，而是**全年毛利 ÷ 全年收入**（加权口径）
- 折叠后的「1–N 月累计」列同理，用累计毛利 ÷ 累计收入
- 毛利率为负时标红；收入为 0 而成本有值时，毛利率留空（不报错）

## 其他功能

- **销项税**：自动计算，也可手动覆盖，手改后单元格变黄底并出现 ↺ 恢复按钮
- **进项税**：手工填写
- **增值税**：负数标红并提示留抵，附加税基数按 0 计
- **附加税费**：默认城建 7%、教育 3%、地方教育 2%，带**六税两费减半开关（默认开 → 3.5/1.5/1）**，每个费种均可手动覆盖
- **四个税负率**：本月/本年 × 增值税税负率/综合税负率，分母为 0 时留空不报错
- **折叠累计**：点任一月表头，前面所有月份折叠成一列「1–N月累计」，点累计表头展开
- **三行高亮**：收入合计行（绿）、增值税行（紫）、税金合计行（蓝）整行填色，企业所得税等其他行不填色，深浅两套主题各自适配

## 数据存储

所有数据只存在**当前浏览器的 localStorage**，不上传任何服务器。

- 换浏览器、换电脑、清缓存 → 数据不会跟过去
- 重要数据请用「导出存档」保存 JSON，或「导出 Excel」留档
- 旧版存档（含税率设置、自定义税种、印花税开关）打开时自动迁移到行模型，数据不丢

## 导入导出

- **导出 Excel**：真正的 `.xlsx`（自写 ZIP + OOXML），含 `明细台账` 和 `税负率` 两个工作表，月份为列、项目为行，空白月留空不写 0。两个表都带「主营业务成本 / 毛利 / 毛利率」三行，毛利率写成真正的百分比格式（0.00%）
- **导出样式**：按金哪达既有台账模板的观感排版——深蓝标题条（金字）+ 绿色分节带（一、基础经营数据 / 二、增值税计算明细 / 三、附加税及其他税种明细 / 四、税负分析）+ 红色加粗的计算项 + 浅灰数值格 + 细边框，合计行整行绿底加粗，首页两行与前两列冻结；数字右对齐、千分位、两位小数，百分比为 0.00%
- **导入 Excel**：支持 `.xlsx` / `.xls`（网页表格形式）/ `.csv`。按首列名称识别项目（含「主营业务成本 / 营业成本 / 销售成本」），**表里有、本地没有的项目会自动建行**并带入数据；销项税与附加税费的导入值若与自动计算值相差超过 0.005，自动标记为手动覆盖

## 本地使用

`index.html` 直接用浏览器打开即可，功能与线上完全一致。注意本地文件与线上网页属于不同的存储域，两处数据互不相通。
