## 10:40 税金台账新增「导入科目余额表」

需求：给单文件 HTML 税金台账加一个入口，读金蝶导出的科目余额表（桌面 `科目余额表_广州金哪达贸易有限公司_2026-10_…xlsx`），
按 `映射表.xlsx`（台账项目/科目编码/科目名称/取数口径）把**本期发生额**自动填进文件标注的那个月份，其它月份不动。

实现要点（都在 index.html）：
- `DEF_MAP` 13 项内置映射；`S.mapRows` 存自定义映射（localStorage，null=用内置）。`mapRows()` 取当前生效的。
- `readMatrix(file)`：从 importExcel 里抽出来的 csv/xlsx/html 统一读取。
- `balPeriod` 先读表头「2026年10月」再退回文件名「…_2026-10_…」；`balCompany` 读「核算单位：」。
- `balCols(matrix)`：按表头文字认列 —— 找含 `科目编码`+`科目名称` 的行，两层表头（分组名 + 借/贷）或一层表头都吃，
  `grp[c]` 向前继承解决合并单元格；`balPickCol` 用语义组（本期/本年累计/期初/期末）避免「本年累计发生额」被「发生额」误命中。
- 取数：科目编码精确匹配（父科目本身是汇总数，不累加明细），编码找不到再按科目名称找。
- 回退：映射侧本期为空 → 改取对方借/贷方，标「口径回退」；但**增值税/销项/进项/预缴不回退**（借方是缴纳额，会把已缴当应纳）。
  收入项回退到借方取负号（冲减），成本/税费保持正数。
- 落点：`balTarget` 先走 LABELS 认固定行/老行，再名字匹配，最后建行（含「收入」→收入项，否则手工税费）；
  `balPut` 双态行写 override，收入/成本/进项/预缴写本体。
- 归一：导入后按 calcSeries 比一遍，与自动值差 ≤0.005 的 override 删掉（销项/增值税/附加/预缴城建），避免满屏黄底。
- 弹窗 `showBalReport`：13 行明细（项目/科目/口径/金额/说明）+ 未取到数清单 + 撤销/更新映射表/恢复默认映射。
- 撤销：`balUndoState` 存该月 JSON 快照 + 新建行 id，恢复月份并删行。
- 「导入余额表」同一个按钮既认余额表也认映射表（表头有 台账项目+余额表科目编码 → 当映射表更新）。
