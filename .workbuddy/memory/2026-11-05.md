## 税金台账单页应用（已交付）

- 产物：`税金台账.html`（单文件，无依赖，双击浏览器打开即用；localStorage 存本机）。
- 口径：货物 13% / 服务 6%；增值税 = 销项 − 进项（进项手工）；城建 7% / 教育 3% / 地方 2%，

  本年 = 1 月至选中月累计。
- 其他：合计列 sticky 右侧；空白月计算格留空不显示 0.00；负增值税标红并提示留抵；
  导出 .xls（HTML table + x:num）、导出/读取 JSON 存档。
- 验证：Edge headless 截图 + node 跑 calcMonth 回归。9 月 757,496.73 / 进项 71,380.80 →
  增值税 27,093.77、附加 948.28+406.41+270.94、合计 28,719.40、增值税税负率 3.58%（减半口径）。

## 第三轮迭代：点月份折叠前序月份为「累计」列

- 交互：点任一月表头 → 选中该月 + 把 1…(sel) 月折叠成一列 `{a:1,b:sel}` 的「N–M月累计」，
  之后月份照常显示；点累计列表头（带 ▾）展开回 12 列；1 月不可折叠。
- 实现要点：表格改为**按视图列数组重建**（`viewCols()` → `{k:"cum",a,b}` / `{k:"m",i}`），
  `buildGrid()` 每次重建需清空 inputs/calcCells/cumCells/totalCells 四个映射，并**重建后必须再调
  `syncControls()`**，否则印花税/企业所得税的 `opt-off` 行隐藏状态会丢。
- 累计值：`rangeSum(a,b)` 逐月 calcMonth 后求和（输入行取原值、计算行取结果），
  输入行为空且区间无值 → 累计格留空；累计列只读、深蓝底 `--cum-*` 变量、不参与编辑。
- 右侧合计列仍为全年 12 月合计，折叠时表头文案改「全年合计」以免误读。
- 验证：headless 注入点击后 dump，1–5 月累计 510,000 与逐月值、展开后 12 列值全部对上。

## 第四轮：收入拆三行（货物开票 / 未开票 / 服务）

- 字段：`goods`（货物开票收入，沿用旧名兼容历史存档）、`unbilled`（未开票收入，新增）、`service`。
- 税率：`S.rates.unbilled` 默认 13%（未开票按货物口径），可在「税率设置 → 未开票销项%」单独改；
  销项税 = 开票×r.goods + 未开票×r.unbilled + 服务×r.service。
- 改动清单（改税种行必须同步这几处，漏一处就出错）：
  `GRID` 行 → `blank()` → `defaults().rates` → `calcMonth` → `isBlank` → `paint` 的 setVal →
  `T` 汇总对象 → `CUM_FIELDS` 与 `rangeSum` 的输入字段数组 → 导入 `LABELS` / `DIRECT` →
  `btnLoad` 里的 rates 字面量（缺 unbilled 会算出 NaN）→「计算过程」文案。
- 行标签百分比改为**动态**：GRID 加 `rk`/`half`，buildGrid 输出 `<i data-rk>`，`syncControls` 按当前税率
  与减半开关重写标签（附加行显示 3.5/1.5/1%），不再硬编码。
- 验证：9 月 200,000/80,000/477,496.73 → 收入 757,496.73、自动销项 65,049.80、留抵 −6,331.00、附加 0；
  导入表含「未开票收入」→ 正确映射到 unbilled，9 月销项与城建识别为手改（共 2 处）；
  导出 xlsx 明细表首列为 货物开票收入/未开票收入/服务收入。

## 第五轮：导出「税负率」表补全

- 原缺陷：第二个工作表只有 6 列（月份/收入/增值税/税金合计/两个税负率），
  缺应用里已显示的**本年累计口径**两个税负率，也缺收入三项拆分与销项/进项，看着像漏导。
- 现为 13 列：月份 | 货物开票收入 | 未开票收入 | 服务收入 | 收入合计 | 销项税 | 进项税 |
  增值税(计税基数) | 税金合计 | 本月增值税税负率 | 本年增值税税负率 | 本月综合税负率 | 本年综合税负率。
  末行「1–12月累计」含收入拆分与各项累计；累计行只填「本年」两列，本月两列留空。
- 修掉旧逻辑两个坑：`v:ai?c.base/c.income:0` 用累计收入做除零守卫（错，应按当月收入），
  以及无收入时写 0 而不是留空。
- 口径说明：本表「增值税(计税基数)」= max(销项−进项,0)（税负率分子），
  明细台账「增值税」= 真实差额（可为负、显示留抵），两表故意不同。
- 空月份仍整行只留月份标签，与明细台账一致，不写 0。
- 验证：openpyxl 读回 14 行 × 13 列，百分比 number_format = 0.00%，累计 4.03% / 4.32% 与明细对得上。

## 第六轮：税负率表转置（月份为列、类目为行）

- 用户要求与其原表小汇总块一致：列 = 1月…12月 + 全年累计，行 = 类目。
- 现为 13 行 × 14 列：货物开票收入 / 未开票收入 / 服务收入 / 收入合计 / 销项税 / 进项税 /
  增值税(应纳) / 全部税金 / 本月增值税税负率 / 本年增值税税负率 / 本月综合税负率 / 本年综合税负率。
- 实现：先一次性算出各月 `{m,c,blank}` 与前缀累计（pG/pU/pS/pI/pO/pN/pV/pT）放进 `acc[]`，
  再用 `pushRow(label, monthFn, totalFn, isPct)` 逐行渲染；空白月所有类目格留空；
  四个税负率行标签用 STY.head 加粗、数值用 STY.pct（0.00%）。
- 累计口径：「本月」两个税负率在全年累计列留空，「本年」两个填全年值。
- 验证：openpyxl 读回 13×14，1 月 140,000/18,200/15,200/16,112 与 10.86%/11.51%，累计 4.03%/4.32% 全对。
