### 16:40 导入/导出记住上次文件夹（File System Access）

- 背景：`<input type=file>` 与 `a[download]` 都无法指定目录，只能换 `showOpenFilePicker / showSaveFilePicker`
  （Edge/Chrome，安全上下文）；把上次的 **FileSystemFileHandle** 当 `startIn` 传回去，浏览器就定位到同一文件夹。
- 句柄存 IndexedDB（库 `tax-ledger-fs` / store `handles`，键 `lastFile` / `lastSave`）；
  另有 `FS_MEM` 内存副本，`fsSet` **先写内存再异步落库**（IDB 卡住也不阻塞用户操作）。
  预热只补空值（`if(f && !FS_MEM.x)`），否则慢半拍的 IDB 会把本轮刚选的句柄覆盖成 null —— 踩过。
- 关键实现：
  - `FSA_OK` = 两个 API 都是函数 && `location.protocol !== "file:"` && `isSecureContext !== false`。
    双击本地 html 打开时选择器会抛 SecurityError，直接走老路，避免「点了没反应」。
  - `pickFile(kind)` → File / null（取消）/ undefined（不支持 → 调用方点隐藏 input）；types 按 excel|json 过滤。
  - `saveFile(blob,name,key)` → 实际文件名 / null（取消）；startIn 失效（SecurityError 等）会**不带路径重试一次**，
    两次都不行才退回 `download()`。
  - `fsGet/fsSet` 全部 `raceTimeout`（1200/1500ms）兜底：headless/隐私模式下 `indexedDB.open` 可能永不回调。
- 顺带把「导出存档 / 读取存档」也改成同一套（`loadArchive(file)` 抽出），四个按钮加 title 说明。
- 导出 toast 改成「已保存 文件名（含两个工作表）」。
- 测试（本地 http server + headless Edge + stub 选择器，18 项全过）：首次保存无 startIn、第二次带上次句柄、
  导入优先用 lastSave 目录、二次导入用 lastFile、取消返回 null 且不改记忆、SecurityError 触发重试、JSON 类型过滤、
  点「导出 Excel」端到端 toast 与 startIn 正确；无 API 时 4 项回退断言全过。
  ⚠️ 该 headless 环境 IndexedDB 被禁用（`indexedDB.open` 无任何回调），持久化只能在真浏览器验。
